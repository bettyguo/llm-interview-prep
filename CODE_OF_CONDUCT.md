# Code of conduct

This project adopts the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Short version:

- Be kind. Critique the work, not the person.
- Disagreements on factual content are resolved with sources, not vibes.
- Harassment of any form will not be tolerated.
- Reports go to the curator via the issue tracker, or by email if appropriate.
